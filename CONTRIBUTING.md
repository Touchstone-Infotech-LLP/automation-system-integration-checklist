# Contributing

Thank you for helping improve the Automation & System Integration Checklist.

The goal is to maintain a practical, vendor-neutral resource for designing reliable business automations and integrations.

## Useful contributions

We welcome:

- additional integration checks based on real implementation experience,
- corrections to outdated guidance,
- clearer explanations and edge cases,
- security and reliability improvements,
- references to authoritative vendor or standards documentation,
- formatting and accessibility improvements.

## Contribution principles

Recommendations should be actionable, technically defensible and broadly useful. Where implementation differs by platform, explain the assumption rather than presenting one vendor's behavior as universal.

Please avoid promotional links, exposed credentials or personal data, unsafe security shortcuts, duplicate checklist items and unsupported claims.

## How to contribute

Open an Issue for discussion or submit a focused Pull Request explaining the problem, proposed change and relevant evidence or implementation context.
